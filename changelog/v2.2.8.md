## Added
- **Archive fallback in the media viewer.** Opening images from a thread 4chan has dropped now falls through to the archive, like the thread screen already did.
- **Unindexed vault notice.** The Vault tab now tells you when saved threads are on disk but missing from the index, with a Rescan button right there, instead of looking empty after a reinstall.
- **Upload prompt for every engine.** Reverse searching a local-only file now asks before it leaves your phone, including for TinEye and Yandex, and names where it goes and for how long.

## Changed
- **Startup theme.** The launch screen follows your system theme, so a light-theme phone no longer flashes a dark frame.
- **Faster vault.** Renaming or merging a thread reindexes only that thread, and ticking a file or typing a search no longer resorts the whole vault.

## Fixed
- **Video scrubbing.** Dragging the seek bar shows the time under your finger and seeks once on release, instead of stuttering the whole way.
- **Merging imported threads.** Merging one imported thread into another no longer overwrites the target thread's posts.
- **Dead taps on links.** Opening a link, sharing a file or granting storage access now says "No app can open this link" when nothing on the phone can handle it.
- **Interrupted vault migration.** A one-time vault move that fails partway is retried on the next launch instead of being marked done with files left behind.
- **Stuck install.** Closing the system installer without answering no longer leaves the update spinning; it reports that the installer was closed.
