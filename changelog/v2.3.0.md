## Added
- **Search and sort the vault by thread.** Vault search has a Files/Threads toggle, and under Threads a query matches a saved thread's subject, board or number anywhere in the vault.
- **Sort chips over the thread list.** Saved threads now order by date saved, total size, subject or thread number, reversed like the grids.

## Changed
- **Shuffle across ticked threads.** With items selected, the shuffle button plays those instead of the level on screen, so long-pressing a few threads and pressing shuffle plays them together.
- **Tapping a search result.** Opening a thread from the search results closes the search and lands you inside that thread.

## Fixed
- **Video keeps playing when a download lands.** Saving the video you are watching no longer jumps it back to the start.
- **Empty thread list.** A filter or search that matches no threads says "Nothing matches" instead of showing a blank list.
