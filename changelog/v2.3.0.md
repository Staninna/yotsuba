## Added
- **Vault search and sort by thread.** The Vault tab now finds and orders whole saved threads, not just individual files.
- **Save every file in a thread.** The thread menu has one action that sends all of the thread's media to the vault.
- **Sound filter in the vault.** Videos with audio have their own filter line in the Vault tab.
- **Watched list sort order.** The sort you pick in Watched sticks between launches.
- **Read posts folded under the OP.** A watched thread with unread replies opens at what is new, with the earlier posts collapsed into one row.
- **Vault trash.** A deleted file waits a week in the trash before it goes for good, so it can be put back.
- **Uploads you approve.** Sending a local-only file to a temporary host asks first and says where it goes, and the prompt can be turned off in Settings.
- **Reverse search for local files.** An imported image or a video frame can go to every engine, Google Lens included.

## Changed
- **Shuffle across ticked threads.** Shuffle now draws from the threads you have selected.
- **Picture-in-picture chrome.** The tab bar and top bar stay hidden while the app is in picture-in-picture.
- **Duplicate finder scope.** It rescans first and looks only at what is on screen.

## Fixed
- **Video keeps playing on save.** A download finishing no longer restarts the video you are watching.
- **Frame picker button.** Its button no longer runs into the time label on narrow screens.
- **Bookmarks after a restore.** Restoring a backup refreshes the bookmark list right away.
- **TinEye and Yandex uploads.** Both engines take a direct upload again and open their results page.
- **Video scrubbing.** Dragging the scrubber seeks once at the end instead of stuttering through the drag.
- **Merged threads.** Posts from a merged thread no longer overwrite the target's own posts.
- **Missing app for a link.** Opening a link with no app installed says so instead of failing silently.
- **Unindexed vault.** The Vault tab tells you when media on disk has not been indexed yet, rather than looking empty.
