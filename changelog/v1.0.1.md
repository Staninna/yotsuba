## Changed
- **Update check no longer needs a token** — Yotsuba now reads its releases from the public repo directly, so checking for and installing updates works without any setup.
- **Clearer update errors** — the Updates section now tells you when no release exists yet or when GitHub is rate-limiting, instead of asking you to check a token.
## Removed
- **GitHub token field in Settings** — the "GitHub token (private repo only)" box and its Save button are gone from the Updates section; any token you had saved is discarded.
