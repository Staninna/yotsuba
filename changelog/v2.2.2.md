## Changed
- **Release builds are launched before they ship.** Every release is now installed and started on an emulator before it is published, so an update that crashes on launch, as 1.1.1 did, never reaches your phone.
- **Saved threads are checked before release.** Each release is verified to still read the vault's meta.json and posts.json sidecars, so a saved thread cannot quietly turn up as missing after an update.
