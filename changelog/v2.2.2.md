## Changed
- **Releases are launched before they ship** — every release build is now installed and started on an emulator before it is published, so an update that crashes on launch (as 1.1.1 did) is stopped rather than delivered to your phone
- **Saved threads are checked before release** — each release is verified to still read the vault's `meta.json` and `posts.json` sidecars, so a saved thread can't silently come back as missing after an update
